# kg200

Real Kodak Gold 200 scans (JPEG / PNG / TIFF, any size) used as **references** to calibrate the film look, the grain above
all: grain strength per tone, size of the clumps, colour of the grain. Not processed by the app; measured only.

Prefer the largest files available (originals, not screenshots): screenshots are scaled and recompressed, so the grain size
on the frame cannot be known. Third-party scans: keep them here for measurement only.

Upload on GitHub: open this folder → "Add file" → "Upload files" (browser limit 25 MB per file).
